# BANG! 온라인 (기본판)

친구들과 아이패드·컴퓨터 브라우저로 함께 즐기기 위한 Bang! 웹 버전입니다.
개인적·비상업적 용도로만 사용합니다.

## 실행 방법 (로컬)

1. Node.js 18 이상 설치
2. 프로젝트 폴더에서:

```bash
npm install
npm start
```

3. 브라우저에서 `http://localhost:3000` 접속
   - 같은 와이파이의 다른 기기(아이패드 등)에서는 `http://<내 컴퓨터 IP>:3000` 으로 접속

## 인터넷에 올리기 (친구들이 링크로 접속)

`DEPLOY.md`를 따라 GitHub + Render(무료)에 올리면 `https://….onrender.com` 주소로 어디서든 접속할 수 있습니다.

## 테스트

```bash
npm test                 # 자동 시뮬레이션 + 봇 테스트
node test/simulate.js 8  # 가짜 클라이언트 8명으로 로비→게임→종료
node test/bots.js 6      # 사람 1명 + 봇 6명
node test/characters.js  # 캐릭터 능력 단위 테스트 (17개)
node test/cards.js       # 게임 카드 단위 테스트 (15개)
node test/timers.js      # 제한 시간 자동 진행 테스트
```

특정 캐릭터를 직접 써보고 싶으면 서버를 이렇게 켜면 방장의 캐릭터가 고정됩니다:

```bash
BANG_FORCE_CHAR=kit_carlson npm start        # macOS/Linux
set BANG_FORCE_CHAR=kit_carlson && npm start  # Windows cmd
$env:BANG_FORCE_CHAR="kit_carlson"; npm start # Windows PowerShell
```

## 혼자 테스트하기 (봇)

방을 만든 뒤 대기 화면에서 방장에게 보이는 **🤖 봇 추가** 버튼을 누르면 자동으로 플레이하는 봇이 들어옵니다.
봇은 항상 준비 완료 상태이고, 자기 차례가 되면 약 1초 간격으로 장착 → 맥주 → 뱅! → 턴 종료 순으로 행동하며,
공격을 받으면 <빗나감!>이 있을 때 85% 확률로 피합니다. 직업에 따라 대상을 고르는 단순한 규칙이 있습니다
(무법자는 보안관을 노리고, 부관은 보안관을 공격한 사람을 노리고, 배신자는 마지막까지 보안관을 살려두는 식).
봇 로직은 `server/bot.js` 한 파일에 있습니다.

## 디자인

낡은 서부 술집 테마: 나무 배경·판자 버튼, 펠트 테이블, 낡은 종이 패널·카드, 황동 포인트. 글꼴은 Google Fonts(Do Hyeon, Gowun Dodum, Rye)를 인터넷에서 불러오고, 카드·캐릭터·직업 아이콘은 [game-icons.net](https://game-icons.net) (CC BY 3.0, `public/js/icons.js`에 포함)을 사용합니다.

## 구조

```
server/
  index.js          Express + Socket.io 진입점, 소켓 이벤트 라우팅
  rooms.js          방 생성/참가/준비/관전/설정/채팅/재접속 관리, 봇 추가/제거와 봇 행동 스케줄링
  bot.js            봇 AI (혼자 테스트용)
  game/
    engine.js       게임 규칙 엔진 (서버가 모든 상태를 관리 — 클라이언트는 자기 정보만 받음)
    view.js         플레이어별로 "볼 수 있는 정보만" 추려서 보내는 뷰
    roles.js        인원별 직업 배치표
    characters.js   캐릭터 16종 데이터 (능력 로직은 순차 구현)
    cards.js        게임 카드 80장 데이터 + 카드 정의 (공식 한글판 명칭, 영어명 포함)
public/
  index.html, css/style.css, js/app.js   클라이언트 (빌드 과정 없음)
  js/icons.js       game-icons.net 아이콘 (CC BY 3.0)
  sounds/           효과음·배경음악 파일을 넣는 곳 (선택)
test/
  simulate.js       자동 시뮬레이션 테스트
  bots.js           사람 1명 + 봇 N명 테스트
  characters.js     캐릭터 능력 단위 테스트
  cards.js          게임 카드 단위 테스트
  timers.js         제한 시간 테스트
  screenshots.js    Playwright 화면 캡처 (UI 확인용)
```

## 현재 구현 상태

- 메인 화면: 닉네임 입력 → 방 만들기 / 코드로 참가
- 대기 화면: 참가자 목록, 준비/시작, 관전 전환, 방장 설정(최대 인원, 관전자 채팅), 인원별 직업 배치표, 채팅, 내보내기
- 게임: 직업·캐릭터 랜덤 배정, 보안관 공개, 체력(총알) 표시, 초기 손패, 턴 진행(가져오기→사용→버리기), 사거리 계산(탈락자 제외), 탈락·직업 공개·카드 전부 버림, 벌칙/보상, 승리 판정, 게임 기록, 채팅, 재접속
- 게임 카드 80장 모두 구현 (공식 한글판 명칭): 파란색 17장 — 술통, 다이너마이트, 감옥, 야생마, 조준경, 레밍턴, 카빈, 스코필드, 볼캐닉, 윈체스터 / 갈색 63장 — 뱅!, 맥주, 캣 벌로우, 결투, 기관총, 잡화점, 인디언, 빗나감!, 강탈!, 주점, 역마차, 웰스 파고 은행
- 캐릭터 16종 능력 모두 구현 (윌리 더 키드, 캘러미티 자넷, 키트 칼슨, 바트 캐시디, 시드 케첨, 럭키 듀크, 주르도네, 블랙 잭, 벌쳐 샘, 제시 존스, 수지 라파예트, 슬랩 더 킬러, 로즈 둘란, 엘 그링고, 엉클 윌, 클라우스)
- "카드 펼치기!" 판정 시스템 (술통·다이너마이트·감옥·주르도네·럭키 듀크 공용). 펼친 카드는 테이블 가운데에 무늬·숫자와 함께 잠시 표시
- 다이너마이트는 이 게임만의 규칙: 사용 즉시 사용자부터 차례로 펼치고, 스페이드 2~9가 나온 사람이 체력 2를 잃으면 끝. 사용자의 차례는 그 뒤에 이어짐
- 제한 시간: 차례 60초 / 선택(공격 응답, 잡화점 등) 15초 (방 설정에서 변경). 시간이 지나면 자동으로 처리되고 손패도 체력에 맞게 자동으로 버려짐
- 차례 시작 시 카드 가져오기와 감옥·다이너마이트의 "카드 펼치기"는 본인이 가운데 카드 더미를 눌러서 진행 (시간 초과 시 자동). 블랙 잭의 두 번째 카드는 가운데에 공개되고 알림이 뜸
- 슬랩 더 킬러의 공격에 빗나감!이 부족하면 헛되이 쓰지 못하게 막음
- 관전자·탈락자는 플레이어를 클릭/호버하면 직업과 손패를 볼 수 있음
- 내 차례가 되면 화면 가운데에 큰 알림
- 시각 효과·이벤트 피드: 총알 애니메이션, 피격/회복/탈락 표시, 가운데에 행동 알림
- 소리: 효과음·배경음악 (WebAudio 합성). `public/sounds/`에 mp3를 넣으면 그 파일을 사용 (파일 이름은 그 폴더의 README.txt 참고). 상단 🔊 버튼으로 켜고 끄기
- 턴 종료 후 버리기 단계에서 "카드 사용으로 돌아가기" 가능
- 체력이 0이 될 때 <맥주>로 살아나기 (3명 이상 남았을 때)
- 다른 플레이어에 마우스 올리기(PC) / 탭(터치)하면 캐릭터 능력·장착 카드 설명 팝업
- 혼자 테스트용 봇 추가/제거 (방장 전용)
